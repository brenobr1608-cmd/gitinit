[# Organizador Automático de Arquivos 🚀

Script em Python que automatiza a organização de pastas bagunçadas (como a pasta de Downloads), movendo arquivos automaticamente para subpastas com base nas suas extensões (Imagens, Documentos, Vídeos, etc.).

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- Biblioteca nativa `os` (Manipulação de caminhos e diretórios)
- Biblioteca nativa `shutil` (Movimentação de arquivos)

## 📋 Como Executar
1. Certifique-se de ter o Python instalado.
2. Clone este repositório:
   ```bash
   git clone https://github.com[seu-usuario]/[seu-repositorio].git
   ```
3. Abra o arquivo `main.py` e altere a variável `PASTA_ALVO` para o caminho da pasta que deseja organizar.
4. Execute o script:
   ```bash
   python main.py
   ```
]
